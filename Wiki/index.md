## 추가 확인 필요

- [연구계획 초안](../research_plan.md)의 현금·수익률 정의, 측정 시점, 대상·기간·데이터·방법론·가설을 정하기. 연구 주제만 반영된 상태이며 세부 설계는 확인 필요입니다.
- [[선행연구-현금보유논문비교]]에서 학생의 판단과 남은 한계를 확인하기. 초기 두 자료의 관리 항목 11개는 7개 확인 완료·3개 사용 허가·1개 한계를 유지합니다. 신규 S3의 확인 필요 5개 묶음과 신규 비교는 학생 확인 대기이며 기존 허가를 확대하지 않습니다.
- S3가 주가 BHAR의 근거를 추가했습니다. 일반 현금 수준과 고정 향후 1년 수익률의 정의·정보 시점·실증 근거는 추가 확인하기. 과제 2-5의 신규 Ingest와 세 논문 활용 범위 Query를 수행했습니다. 전체 Lint는 아직 진행 전이며, 추가 논문은 학생이 나중에 제공할 예정입니다. 로컬 그래프 실행은 학생의 작업이며 클라우드에서 화면을 확인한 것으로 표시하지 않습니다.
- 과거 로그의 저장소 밖 첨부 경로는 당시 이력으로 보존했습니다. 현재 참고문서는 루트의 [보존 사본](../LLM-Wiki-참고원문.txt)을 통해 GitHub 복제에서도 읽을 수 있습니다. 공개 Gist의 웹 접근은 차단됐지만 사용자 제공 전문은 읽고 반영했습니다.
